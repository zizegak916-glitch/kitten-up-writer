# KittenUp Writer

这是我在写长篇小说时自用的写作助手。写作久了，总会遇到这些问题：

- **设定会乱掉**：人物背景、世界规则写着写着就忘记了。
- **角色性格漂移**：前一章冷静，后一章突然冲动，自己都觉得别扭。
- **伏笔忘记回收**：埋下了钩子，过几章却再也想不起来。

为了不再翻文档翻到崩溃，我开始整理出一套流程，让语言模型帮我做这些琐事。KittenUp Writer 不是聊天机器人，也不是某个官方产品，它就是我用来写作的工具箱。

## 工具箱里有什么

- **设定整理**：把零碎的世界观设定汇总成一份清晰的档案。
- **角色档案**：分析已写内容，提炼角色的性格、动机和关系，写作时随时查阅。
- **章节规划**：根据故事走向自动生成下一章提纲，帮我理清剧情节奏和情绪变化。
- **一致性检查**：看看有没有前后矛盾、时间线错误或者角色行为不符。
- **续写**：当卡壳时，给出几段符合当前文风的续写片段，用来找灵感。

目前这些功能主要通过自定义提示词与大语言模型交互实现，只在本地使用。仓库里的文档和示例是我写作时的记录，既方便自己整理，也希望对同样在写故事的朋友有帮助。

## 如何阅读

- `PROJECT.md` — 我对这个工具的整体思路和各模块构想。
- `docs/writing-workflow.md` — 我的写作流程和使用案例。
- `docs/product-design.md` — 每个模块背后的设计想法。

`plans.md` 记录的是一些随手的改进计划，可能会实现，也可能只是灵感备忘。

如果你也在写小说，欢迎参考、试用，或按照自己的需求修改 prompts。我不是专家，只是把自己的经验整理出来，希望对你有所帮助。
